Kebijakan Privasi Buku Kas Saku

Berlaku sejak 23 Oktober 2026

Buku Kas Saku adalah aplikasi pencatat keuangan pribadi. Halaman ini menjelaskan data apa yang disimpan, di mana disimpan, dan bagaimana kamu bisa menghapusnya.

Data yang dicatat

Aplikasi hanya menyimpan data yang kamu masukkan sendiri: tanggal, jenis (pemasukan atau pengeluaran), kategori, jumlah, dan catatan singkat untuk setiap transaksi.

Tempat data disimpan

  • Di perangkatmu. Semua catatan disimpan di penyimpanan browser pada perangkat yang kamu pakai.
  • Di Google Drive milikmu, jika kamu menghubungkannya. Salinan catatan disimpan sebagai satu file di folder data aplikasi (application data folder) di Google Drive akunmu sendiri. Folder ini tersembunyi dari daftar file Drive.

Aplikasi ini tidak memiliki server sendiri. Pembuat aplikasi tidak menerima, melihat, atau menyimpan catatan keuanganmu.

Akses ke akun Google

Saat kamu menghubungkan akun Google, aplikasi hanya meminta izin https://www.googleapis.com/auth/drive.appdata. Izin ini terbatas pada folder data milik aplikasi ini saja. Aplikasi tidak dapat membaca, mengubah, atau menghapus file lain di Google Drive-mu.

Aplikasi juga membaca alamat email akun Google yang terhubung, semata-mata untuk ditampilkan kepadamu sebagai penanda akun yang sedang dipakai.

Penggunaan data dari Google API oleh aplikasi ini mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.

Berbagi data

Data tidak dijual, tidak dibagikan kepada pihak lain, dan tidak dipakai untuk iklan atau pelacakan. Aplikasi tidak memakai analitik maupun cookie pelacak. Huruf (font) dimuat dari Google Fonts.

Menghapus data

  • Di perangkat: hapus data situs atau data aplikasi Buku Kas Saku melalui pengaturan browser atau pengaturan aplikasi di HP.
  • Di Google Drive: buka Google Drive di komputer, pilih Setelan, lalu Kelola aplikasi. Pada Buku Kas Saku, pilih Opsi untuk menghapus data aplikasi tersembunyi atau memutus aksesnya.
  • Mencabut izin Google: buka myaccount.google.com/permissions dan hapus akses Buku Kas Saku.
